By installing this software, you acknowledge that you are using an experimental tool designed for academic purposes.

## 🚀 Installation Overview
While this application offers a lucrative ease of installation (a simple side-loadable APK), modern Android security features require manual configuration to allow the system’s advanced automation features to function correctly. 

Please follow the steps below carefully to ensure the system works as intended.

---

## 🛠️ Setup Instructions

### Step 1: Disable Google Play Protect
Because this is not an official app on the Play Store, Google Play Protect may block the installation.
1. Open the **Google Play Store** app.
2. Tap your **profile icon** (top right).
3. Select **Play Protect** > **Settings** (gear icon).
4. Turn off **"Scan apps with Play Protect."**

### Step 2: Install the APK
1. Download the `ThesisSystem.apk` to your device: [Download ContextualAssistant.apk](https://github.com/Hyper-Intelligent-Monkey/Context-Aware-Thesis-APK/raw/main/ContextualAssistant.apk)
2. Tap the file to install. If prompted, **"Allow installation from unknown sources"** for your browser or file manager.

### Step 3: Unlocking "Restricted Settings" (Crucial)
On Android 13 and newer, the system automatically restricts Accessibility Services for side-loaded apps. You must manually unlock this:
1. Go to your phone's **Settings**.
2. Navigate to **Apps** > **See all apps**.
3. Find and tap on **ThesisSystem**.
4. Tap the **three dots (⋮)** in the top-right corner, if not available look for "Restricted Settings" in app info.
6. Select **"Allow restricted settings."** (Authenticate with your PIN/Fingerprint if asked).

### Step 4: Granting System Permissions
1. Open the **ThesisSystem** app from your app drawer.
2. The app will prompt you for the following permissions:
    * **Accessibility Service**: Required for the system to "see" the screen and navigate on your behalf.
    * **Overlay Permission**: Allows the system to draw highlighters and floating control windows over other apps.
3. Follow the on-screen prompts to enable these in your system settings.

---

## 📖 How to Use
Once the setup is complete:
1. Ensure the **Floating Window** is visible on your screen, Accessiblity Services is enabled, and connected to a network.
2. Navigate to any third-party application you wish to interact with.
3. Input the navigational query or application feature you wish to locate.
